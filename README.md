# Christopher "El Tanque" Ozana

Site estático (HTML/CSS/JS) do atacante do Paulista FC, criado em Várzea Paulista.

- Abrir: dar duplo clique em `index.html` ou publicar a pasta (GitHub Pages, Netlify, etc.).
- Ações sociais: editar `data/acoes.js`.
- Fotos: hospedadas no arquivo do Paulista FC (créditos no site). Para uso comercial/produção, pedir autorização ao clube/fotógrafos ou trocar por fotos próprias em `script.js`.
- Fontes dos dados: arquivo.paulistadejundiai.com.br, ogol.com.br, Tribuna de Jundiaí, Jornal de Jundiaí.
